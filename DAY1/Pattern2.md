# Pattern2 Documentation

## Purpose
This file demonstrates a triangular pattern of `*` symbols, where the number of symbols in each row corresponds to the row number (starting from 1).

## Pattern Output
The pattern generated by the script is as follows:

(blank line)
*
* *
* * *
* * * *


## Code Explanation
1. **Symbol Definition:**
   - The `*` symbol is used to create the pattern.

2. **Outer Loop (Rows):**
   - The outer loop determines the number of rows in the pattern.
   - In this case, there are 5 rows (from `i = 0` to `i = 4`).

3. **Inner Loop (Symbols in Each Row):**
   - The inner loop determines the number of symbols printed in each row.
   - For each row `i`, the inner loop runs `i` times, printing `i` symbols.

4. **Printing Behavior:**
   - The `end=' '` argument ensures that symbols are printed on the same line, separated by spaces.
   - A `print()` statement after the inner loop moves to the next line after completing a row.

5. **Special Case for `i = 0`:**
   - When `i = 0`, the inner loop does not run, and only a blank line is printed.

## Key Points
- The pattern is a right-angled triangle of `*` symbols.
- The number of symbols in each row corresponds to the row number (starting from 1).
- The script uses nested loops to generate the pattern.

## Usage
This pattern can be used as a basic example to understand nested loops, conditional execution, and printing in Python.
