# Pattern2Optimized Documentation

## Purpose
This script generates a right-angled triangle pattern of symbols using an optimized approach. The number of symbols in each row corresponds to the row number (starting from 1). The script uses string multiplication to simplify the process.

## Pattern Output
The pattern generated by the script (for 5 rows) is as follows:

```
*
* *
* * *
* * * *
* * * * *
```



# ✨ `print_triangle()` Function - Detailed Explanation

## 🔍 Function Definition

```python
def print_triangle(symbol="* ", rows=5):
```

This line defines a function named `print_triangle` that accepts two optional parameters:

* `symbol="* "` → a string (default: a star with a space)
* `rows=5` → an integer (default: 5 rows)

## 🧠 Understanding Each Part in Depth

### 1. `def`

* This keyword is used to **define a function** in Python.

### 2. `print_triangle`

* This is the **function name**. You can call it later using `print_triangle()`.

### 3. `symbol="* "`

* This parameter is a **default argument**.
* If the user doesn't provide a symbol, it will use `"* "` by default.
* It is a **string type** and can be any printable character(s), such as:

  * `"@"`, `"x"`, `"# "`, or even an emoji like `"🌟 "`

### 4. `rows=5`

* This is another **default argument**, set to the integer `5`.
* It controls **how many rows** the triangle will have.
* The user can override it by passing a custom value.

## ✅ Function Flexibility – Usage Examples

### 🔹 Default usage:

```python
print_triangle()
```

**Output:**

```
*
* *
* * *
* * * *
* * * * *
```

### 🔹 Custom number of rows:

```python

```



```
♥

♥ ♥ ♥ ♥
```

## ⚠️ Notes on Valid Input

⚠️ **Notes on Valid Input**

- `symbol` should always be a **string**.
  - ❌ If you pass an **integer** like `symbol=5`, it may not raise an immediate error, but the output will be incorrect (you’ll see numbers instead of repeated symbols).
  - ✅ To ensure proper output, use a **string** like `"*"` or `"# "` as the symbol.

- `rows` should be a **non-negative integer**.
  - ❌ If you pass a **string** like `rows="5"`, it will raise a `TypeError` because `range()` expects an integer.
  - ⚠️ If you pass a **negative value** like `rows=-3`, it won’t raise an error, but it will produce **no output** because `range(1, -2)` is empty.

✅ **Tip:** Add type checks to your function to prevent such invalid inputs and provide meaningful error messages.

## 📌 Looping

```python
for i in range(1, rows + 1):
```

* Iterates from `1` to `rows` (inclusive).
* Controls how many times the symbol will be printed per row.

## ✳ String Multiplication

```python
print(symbol * i)
```

* Repeats the symbol `i` times to build each row of the triangle.

## 📝 Print and Pattern

* **Print**: Each row is printed using the `print()` function, which adds a newline automatically.
* **Pattern Shape**: The result is a **left-aligned right-angled triangle**.
